AlliedBits.Tlumach.UWP integrates [Tlumach.NET](https://www.nuget.org/packages/AlliedBits.Tlumach) with UWP applications on .NET 9 and later.

* Its `TranslationUnit` class is used by the generated translation classes and is bound to in XAML.
* The UI is updated when the language is switched, without restarting the application.

Requires UWP on .NET 9 or later. The package is built for Windows SDK 10.0.17763, so it works with any later Windows SDK version that the application targets. See the Getting Started section of the [documentation](https://alliedbits.com/tlumach).
