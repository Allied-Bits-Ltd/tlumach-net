AlliedBits.Tlumach.MAUI integrates [Tlumach.NET](https://www.nuget.org/packages/AlliedBits.Tlumach) with .NET MAUI.

* The `Translate` markup extension and the bindings to generated translation units show translations in XAML.
* The UI is updated when the language is switched, without restarting the application.

Requires .NET MAUI 9 or later (Android, iOS, Mac Catalyst, and Windows). See the Getting Started section of the [documentation](https://alliedbits.com/tlumach).
