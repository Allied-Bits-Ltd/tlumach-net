AlliedBits.Tlumach.WinForms integrates [Tlumach.NET](https://www.nuget.org/packages/AlliedBits.Tlumach) with Windows Forms.

* The `TranslationProvider` component adds translation keys to controls, menu items, and list view columns in the Visual Studio Designer.
* The `BindTranslation` methods bind controls to translation units in code.
* The controls are updated when the language is switched, without restarting the application.

Requires .NET Framework 4.7.2 or later, or .NET 9 or later on Windows. See the Getting Started section of the [documentation](https://alliedbits.com/tlumach).
