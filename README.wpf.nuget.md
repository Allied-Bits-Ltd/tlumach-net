AlliedBits.Tlumach.WPF integrates [Tlumach.NET](https://www.nuget.org/packages/AlliedBits.Tlumach) with WPF.

* The `Translate` markup extension and the bindings to generated translation units show translations in XAML.
* The UI is updated when the language is switched, without restarting the application.

Requires .NET 9 or later on Windows. See the Getting Started section of the [documentation](https://alliedbits.com/tlumach).
